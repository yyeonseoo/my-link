## 1. 서비스 개요 (Overview)

### 1.1 서비스 정의
**"마이링크(MyLink)"**는 누구나 1분 만에 자신만의 멀티 링크 페이지를 만들고 공유할 수 있는 토스 스타일의 미니멀 링크트리(Linktree) 클론 서비스입니다.

### 1.2 기획 배경 및 문제 정의
- 기존 멀티링크 도구는 복잡한 설정 단계와 과도한 유료 결제 유도(Pro 플랜 기능 제한)로 인해 진입장벽이 존재함.
- 국내 사용자와 크리에이터에게 가장 익숙하고 신뢰감 있는 **토스(TDS) 스타일의 군더더기 없는 UI/UX**를 제공하여, 최소한의 클릭으로 완성도 높은 프로필 링크 페이지를 제작·운영할 수 있도록 함.
- 초기 MVP 단계에서는 별도의 복잡한 클라우드 DB 계정 연결 없이도 **브라우저 로컬 스토리지(LocalStorage)**를 활용해 즉각적으로 편집·테스트가 가능하도록 구현함.

### 1.3 핵심 목표 (Success Metrics)
- **제작 소요 시간 단축**: 첫 방문 후 3분 이내에 프로필 링크 페이지 생성 및 공유 링크 복사 완료.
- **실시간 반응성**: 좌측 에디터에서 수정한 내용이 우측 모바일 목업에 즉각(0초 지연) 반영.
- **모바일 완결성**: 방문자가 접속하는 공개 링크 페이지(`/@username`)의 모바일 최적화 및 쾌적한 반응 속도.

## 3. 사용자 시나리오 (User Scenarios)

본 서비스는 **링크를 만들고 관리하는 '소유자(Owner)'**와 **공개된 링크를 열람하고 소비하는 '방문자(Visitor)'**의 두 축으로 나뉩니다. 각 주체별 핵심 시나리오는 다음과 같습니다.

### 3.1 소유자(Owner / Creator) 관점 시나리오

#### 시나리오 1-A: 신규 프로필 생성 및 최초 배포 (온보딩)
* **페르소나**: 인스타그램과 유튜브를 운영하는 20대 일상·테크 크리에이터 지우
* **목표**: 인스타그램 바이오 링크 1개 한계를 극복하기 위해, 주요 링크 3개를 모아 3분 안에 배포.
* **사용자 여정 (Journey)**:
  1. **접속 & 핸들 선점**: 마이링크 메인 화면에서 간편 소셜 로그인 후 인스타그램 계정과 동일한 `/@jiwoo` 핸들을 선점합니다.
  2. **프로필 설정**: 본인의 밝은 프로필 사진을 등록하고, "안녕하세요, 일상과 테크를 기록하는 지우예요"라는 토스풍 해요체 소개글을 작성합니다.
  3. **소셜 아이콘 & 링크 등록**: 하단 소셜 바에 인스타그램/유튜브 바로가기를 켜두고, '🔥 이번 주 최신 영상', '지우의 소장템 마켓', '네이버 블로그' 3개 버튼을 등록합니다.
  4. **실시간 미리보기 & 테마 선택**: 우측 모바일 목업을 보며 '토스 클래식' 화이트/블루 테마를 확인하고 '최신 영상' 링크를 드래그 앤 드롭으로 최상단으로 옮깁니다.
  5. **완료 및 배포**: '프로필 링크 복사하기' 버튼을 눌러 인스타그램 프로필 바이오에 붙여넣습니다. (소요 시간: 약 2분 30초)

#### 시나리오 1-B: 링크 일상 관리 및 임시 비활성화 (지속적 운영)
* **페르소나**: 마켓 공구 기간이 끝난 크리에이터 지우
* **목표**: 삭제할 필요 없이 지난 이벤트 링크를 일시 비공개하고, 새 링크로 순서를 교체.
* **사용자 여정 (Journey)**:
  1. **에디터 접속**: 브라우저에서 마이링크 관리자 에디터에 접속하면, 로컬 스토리지에 저장되어 있던 기존 프로필 데이터가 즉시 불러와집니다.
  2. **활성 토글 스위치 조작**: 종료된 '지우의 소장템 마켓' 링크의 토글 스위치를 `OFF`로 전환합니다. (우측 미리보기 목업에서 해당 버튼이 즉시 사라지는 것을 확인)
  3. **새 링크 추가 & 정렬**: 새로 오픈한 '브이로그 Q&A 설문지' 링크를 추가하고 최상단으로 끌어올립니다.
  4. **자동 저장**: 별도의 저장 버튼을 누를 필요 없이 즉시 반영되어 안심하고 에디터를 닫습니다.

#### 시나리오 1-C: 전문성 브랜딩 및 포트폴리오 커스텀 (개발자/구직자)
* **페르소나**: 채용 지원 및 커피챗 네트워킹을 준비하는 개발자 민수
* **목표**: 깃허브, 기술 블로그, 이력서, 포트폴리오 데모를 개발자 친화적인 다크 모드로 단정하게 제시.
* **사용자 여정 (Journey)**:
  1. **브랜딩**: `/@minsoo.dev` 핸들을 개설하고 상태 문구에 "🌱 지금 바이브 코딩 공부 중이에요"를 입력합니다.
  2. **태그 및 뱃지 설정**: `#Next.js`, `#React`, `#TDS` 역량 태그를 칩 형태로 추가하고, 대표 프로젝트에 'NEW' 및 'FEATURED' 뱃지를 설정합니다.
  3. **테마 변경**: '토스 다크' 테마를 선택하여 차분하고 모던한 블랙/다크그레이 무드를 완성합니다.
  4. **이력서 반영**: 링크 주소를 이력서 연락처란과 오픈채팅 공지에 첨부합니다.

### 3.2 방문자(Visitor / End-User) 관점 시나리오

#### 시나리오 2-A: 모바일 SNS 인앱 브라우저를 통한 유입 및 탐색
* **페르소나**: 인스타그램 스토리 링크를 통해 접속한 팔로워 수연
* **목표**: 크리에이터가 추천한 최신 영상과 소장품 정보를 빠르게 확인.
* **사용자 여정 (Journey)**:
  1. **빠른 로딩 진입**: 인스타그램 인앱 브라우저에서 `mylink.com/@jiwoo`를 탭하자 지연 없이 0.5초 만에 깔끔한 모바일 풀스크린 카드 UI가 로딩됩니다.
  2. **직관적 탐색**: 크리에이터의 아바타, 소개글, 태그 칩을 훑어본 후, 눈에 띄는 '🔥 이번 주 최신 영상' 버튼을 탭합니다.
  3. **외부 링크 이동**: 새 브라우저 창 또는 유튜브 앱이 부드럽게 열리며 목표 콘텐츠를 시청합니다.

#### 시나리오 2-B: 소셜 채널 둘러보기 및 타인에게 프로필 공유
* **페르소나**: 지우의 마이링크가 마음에 들어 친구에게 추천하고 싶은 방문자 정우
* **목표**: 크리에이터의 다른 소셜 계정(유튜브, 블로그)을 확인하고, 친구 단톡방에 링크를 공유.
* **사용자 여정 (Journey)**:
  1. **소셜 바로가기 이용**: 프로필 상단의 소셜 아이콘 바에서 '유튜브' 아이콘을 눌러 구독 페이지를 확인합니다.
  2. **원클릭 공유**: 화면 우측 상단의 '공유하기' 버튼을 누르자 하단에 부드럽게 "프로필 링크를 복사했어요"라는 토스 토스트 메시지가 나타납니다.
  3. **전달**: 복사된 주소를 카카오톡 친구 단톡방에 붙여넣어 크리에이터를 추천합니다.

### 3.3 소유자 vs 방문자 핵심 요구사항 매핑

| 구분 | 소유자(Owner)가 경험하는 가치 | 방문자(Visitor)가 경험하는 가치 |
| :--- | :--- | :--- |
| **속도 & 반응성** | 1분 만에 끝나는 생성 및 실시간 모바일 목업 확인 | 모바일 인앱 브라우저에서도 0.5초 이내 즉각적인 쾌속 로딩 |
| **편의성** | 복잡한 관리자 패널 대신 직관적인 토스풍 2-칼럼 에디터 | 큼직하고 누르기 편한 모바일 최적화 버튼 및 시각적 위계 |
| **운영 유연성** | 드래그 앤 드롭 정렬, 활성/비활성 스위치, 자동 영속화 | 비활성화된 만료 링크 없이 최신의 정돈된 링크만 노출 |
| **브랜딩** | 토스 클래식, 다크 등 원클릭 5종 테마 전환 | 신뢰감 있고 피로도가 낮은 깔끔한 토스 디자인 감성 |
| **확산성** | 생성 즉시 원클릭으로 클립보드에 내 링크 복사 | 상단 공유 버튼을 통해 언제든 친구나 타인에게 재공유 |

## 4. 정보 구조 및 사용자 흐름 (IA & User Flow)

### 4.1 사이트맵 (Site Architecture)
```
마이링크 (MyLink)
├── / (랜딩 페이지 & 핸들 등록 / 소셜 로그인 모달)
├── /admin (관리자 대시보드 / 에디터)
│   ├── [좌측] 편집 패널 (프로필 정보 / 소셜 아이콘 / 링크 목록 / 테마 선택)
│   └── [우측] 실시간 모바일 목업 미리보기 (Live Preview)
├── /admin/analytics (간이 통계 대시보드 - 누적 클릭수)
└── /@[username] (공개 멀티링크 프로필 페이지)
```

### 4.2 핵심 사용자 흐름 (User Flow)
1. **시작 & 핸들 등록**: 사용자가 원하는 고유 핸들(예: `@toss_creator`) 입력 후 시작 (소셜 로그인 연동 시뮬레이션 지원).
2. **에디터 진입**: 좌측 패널에서 프로필 사진, 닉네임, 소개글 입력 및 소셜 아이콘(인스타그램 등) 등록.
3. **링크 등록 및 정렬**: 버튼 링크 추가(제목, URL, 아이콘), 드래그 앤 드롭으로 순서 변경, 온/오프 토글.
4. **테마 선택**: 토스 블루, 토스 다크, 쿨 그레이 등 3~5종 프리셋 중 원하는 스타일 선택.
5. **실시간 검증**: 우측 모바일 목업에서 변경 사항을 즉시 인터랙션해보고 확인.
6. **공유 및 배포**: 생성된 고유 링크(`/@username`)를 복사하여 SNS 프로필에 등록.

## 5. 상세 기능 요구사항 (Functional Requirements)

### F-01. 사용자 인증 및 핸들(URL) 관리
- **고유 핸들 선점**:

## 6. 데이터 스키마 및 상태 관리 (Data Schema & Zustand State Architecture)

### 6.1 데이터 모델 인터페이스
```typescript
export interface SocialLink {
  platform: 'instagram' | 'youtube' | 'github' | 'twitter' | 'tiktok' | 'email' | 'other';
  url: string;
}

export interface LinkItem {
  id: string;             // 고유 식별자 (uuid 또는 timestamp)
  title: string;          // 버튼 텍스트
  url: string;            // 목적지 URL
  icon?: string;          // Lucide icon identifier (예: 'Globe', 'ShoppingBag', 'FileText')
  isActive: boolean;      // 노출 여부 토글 (default: true)
  order: number;          // 정렬 순서 인덱스 (0, 1, 2...)
  clickCount: number;     // 누적 클릭 수
  createdAt: string;      // ISO Date string
}

export interface UserProfile {
  handle: string;         // 고유 핸들 (예: 'yyeonseoo')
  name: string;           // 표시 이름 (예: '김토스')
  bio: string;            // 한 줄 소개
  avatarUrl: string;      // 프로필 이미지 Base64 or URL
  themeId: 'toss-classic' | 'toss-dark' | 'soft-blue' | 'mono-minimal' | 'warm-sunset';
  socialLinks: SocialLink[];
  links: LinkItem[];
  totalViews?: number;    // 프로필 조회수
  updatedAt: string;
}
```

### 6.2 Zustand 전역 스토어 (`useProfileStore`) 설계
- **선정 라이브러리**: `zustand` + `zustand/middleware (persist)`
- **스토리지 키**: `name: 'mylink_user_profile'`
- **스토어 구조 및 Actions**:
  - `profile`: 현재 사용자 프로필 및 링크 전체 상태 (`UserProfile`)
  - `updateProfile(data: Partial<UserProfile>)`: 닉네임, 소개글, 아바타 등 기본 정보 업데이트
  - `addLink(item: Omit<LinkItem, 'id' | 'order' | 'clickCount' | 'createdAt'>)`: 새 링크 추가
  - `updateLink(id: string, updates: Partial<LinkItem>)`: 링크 정보/활성화 토글 수정
  - `deleteLink(id: string)`: 링크 삭제
  - `reorderLinks(startIndex: number, endIndex: number)`: 드래그 앤 드롭 순서 재배열
  - `incrementClick(id: string)`: 공개 페이지 링크 클릭 수 +1
  - `setTheme(themeId: ThemeId)`: 테마 프리셋 실시간 변경
  - `resetToDefault()`: 기본 토스 샘플 데이터로 리셋
  - `importData(data: UserProfile)`: JSON 데이터 불러오기/복원

## 7. UI/UX 디자인 시스템 가이드: shadcn/ui 기반 토스 디자인 시스템(TDS) 구축

본 프로젝트의 모든 UI는 **[shadcn/ui](https://ui.shadcn.com/)** 컴포넌트 아키텍처(Radix UI / Tailwind CSS v4)를 기반으로 하되, 루트의 [`design.md`](file:///c:/Users/USER/mylink/design.md)에 기술된 **토스 디자인 시스템(TDS)** 핸드오프 명세(컬러, 타이포그래피, 모서리 라운딩, 터치 인터랙션, 모션)를 100% 충실히 이식하여 구현합니다.

### 7.1 구축 철학 및 아키텍처 연계 원칙
1. **헤드리스 기반 토스 룩앤필 완성**:
   - shadcn/ui는 소스 코드 직접 소유형 라이브러리로, Radix UI의 접근성(WAI-ARIA, 키보드 인터랙션)을 유지하면서 스타일을 완전히 TDS 규격으로 자유롭게 개조할 수 있습니다.
   - 모든 신규 UI 컴포넌트는 공식 CLI(`npx shadcn@latest add <component>`)로 `@/components/ui/`에 생성한 뒤, `design.md`의 TDS 스펙에 맞춰 CVA(Class Variance Authority) 및 Tailwind 클래스를 수정합니다.
2. **단일 진실 공급원 (Single Source of Truth)**:
   - 디자인 토큰은 [`src/app/globals.css`](file:///c:/Users/USER/mylink/src/app/globals.css)의 CSS 변수와 Tailwind `@theme inline`에 선언된 TDS OKLCH 값을 표준으로 참조합니다.
   - 컴포넌트 스타일 결합 시 `@/lib/utils.ts`의 `cn()` 유틸리티를 필수 사용합니다.

### 7.3 타이포그래피 (Toss Product Sans 규격 준용)
- **서체**: `Pretendard Variable`, Sans-serif (TPS의 1:1 공식 무료 대체 폰트).
- **행간 & 자간**: 한글 가독성을 고려한 1.5 Line-height 및 -1%~-2% tight letter-spacing.
- **문장형 버튼 라벨**: "토스의 버튼은 장식이 아닌 문장처럼 읽힌다" 원칙에 따라 명확하고 친절한 문장형 레이블 사용 (예: "프로필 링크 복사하기", "새 링크 추가하기").
- **숫자 표기**: 금융/조회수 데이터는 `tabular-nums` (고정폭)를 적용하여 정렬 흐트러짐 방지.

### 7.4 모서리 라운딩 (TDS Radius) 체계
토스는 "프로덕션에서 가장 둥근 모바일 시스템" 중 하나로 규정됩니다.
- **버튼 스케일별 라운드**: XL 16px / L 14px / M 12px / S 10px.
- **텍스트 인풋**: 12px (`radius-m`).
- **카드 / 컨테이너**: 16px ~ 24px (`radius-xl` ~ `radius-3xl`).
- **시트 / 다이얼로그**: 20px (`radius-2xl`).
- **칩 / 태그 / 토글**: 999px (`radius-full`).

### 7.5 모션, 인터랙션 및 엘리베이션
1. **평면(Flat) 원칙**:
   - 배경은 무조건 평면이 기본이며 불필요한 드롭 섀도우를 배제하고 **1px `grey-200` 헤어라인 보더**로 면을 구분.
2. **햅틱 터치 피드백 (Tactile Feel)**:
   - 모든 클릭 가능 요소에 `active:scale-[0.98] transition-all duration-120`을 부여하여 즉각적인 물리적 반응감 제공.
   - 프레스 상태 시 26% 다크 오버레이(`overlay-press`) 감각의 자연스러운 틴트 적용.
3. **엄격한 비활성화(Disabled) 표준**:
   - 컴포넌트 부분 회색 처리 대신 **전체 노드 `opacity-30 disabled:pointer-events-none`** 적용 (`design.md`의 `disabled-opacity: 0.30`).
4. **절제된 엘리베이션**:
   - 그림자는 플로팅/모달 계층에만 적용 (`shadow-1` 메뉴, `shadow-3` 다이얼로그, `shadow-toast` 토스트).
