# [와이어프레임] 마이링크 메인 화면 (방문자 뷰)

> **대상 화면**: 방문자가 접속하는 공개 멀티링크 페이지 (`/@username`)  
> **디바이스 규격**: Mobile-First (가로 폭 375px ~ 420px 최적화 및 데스크톱 중앙 정렬)  
> **기반 디자인**: 토스 디자인 시스템 (TDS, `design.md` 준용)

## 2. 세부 컴포넌트 명세

| 영역 | 컴포넌트 | 세부 요소 및 TDS 디자인 규칙 | 인터랙션 명세 |
| :--- | :--- | :--- | :--- |
| **1. TopBar** | 상단 헤더 | • 좌측: `M` 심볼 + `마이링크` 로고 텍스트 (17px Bold)<br/>• 우측: 36px 원형 `공유하기` 아이콘 버튼 | 버튼 터치 시 URL 클립보드 복사 & 하단 토스 토스트 메시지 출력 |
| **2. 히어로 카드** | 프로필 서피스 카드 | • 모서리 라운딩: `rounded-[26px]`<br/>• 서피스 배경: White (`#FFFFFF`) / Dark (`#1C1C1F`)<br/>• 외곽 테두리: `border border-[#E5E8EB]/80`<br/>• 56px 원형 아바타 (`bg-[#E8F3FF]`, Toss Blue 이니셜)<br/>• 핸들 및 상태 뱃지 (`@username`, `🌱 상태`)<br/>• 헤드라인: 22px Bold 해요체 ("안녕하세요, ~예요")<br/>• 소개글: 14px Regular (`#4E5968`)<br/>• TDS 칩스: 28px 높이의 둥근 알약형 태그<br/>• 소셜 바: 36px 원형 아이콘 버튼 (인스타, 깃허브 등) | • 소셜 아이콘 호버 시 배경색 전환<br/>• 터치 시 `active:scale-95` 피드백 |
| **3. 주요 링크 카드** | ListRow 그룹 카드 | • 모서리 라운딩: `rounded-[26px]`<br/>• 디바이더: `divide-y divide-[#F2F4F6]`<br/>• 각 행(Row):<br/>  - 40px 정방형 둥근 아이콘 박스 (`rounded-xl`)<br/>  - 타이틀: 15px Semibold (`#191F28`)<br/>  - 뱃지: 10px Bold (`TDS`, `NEW` 등 알약 뱃지)<br/>  - 설명문: 12px Regular (`#8B95A1`)<br/>  - 우측: 16px ChevronRight 화살표 (`#B0B8C1`) | • 행 호버 시 `bg-[#F9FAFB]`<br/>• 클릭 시 새 탭으로 대상 URL 이동 (`target="_blank"`)<br/>• 로컬 통계(클릭 카운트) +1 집계 |
| **4. Primary CTA** | 1차 액션 버튼 | • 높이: 52px (`h-13`), 풀 너비 (`w-full`)<br/>• 모서리: `rounded-2xl` (16px)<br/>• 배경색: 토스 카노니컬 블루 (`#3182F6`)<br/>• 호버/프레스: `#2272EB` / `#1B64DA`<br/>• 그림자: `shadow-[0_4px_12px_rgba(49,130,246,0.28)]`<br/>• 라벨: `프로필 링크 복사하기` (16px Bold White) | 터치 시 클립보드 복사 및 미세 스케일 다운 (`active:scale-[0.99]`) |
| **5. 푸터** | 저작권 표기 | • 중앙 정렬 12px Regular (`#8B95A1`)<br/>• `© 2026 {이름} · 마이링크` | 정적 텍스트 |

## 3. 반응형 대응 (Responsive Behavior)

1. **모바일 뷰 (< 640px)**:
   - 디바이스 가로 폭에 100% 채움 (양옆 `px-4` 패딩 확보).
   - 카드와 버튼들이 엄지손가락 터치 반경에 자연스럽게 들어오도록 최적화.
2. **태블릿 & 데스크톱 (>= 640px)**:
   - 화면 중앙에 최대 너비 `max-w-[420px]`로 스마트폰 실물 디바이스 느낌을 주는 컨테이너로 고정.
   - 배경은 부드러운 토스 그레이(`grey-100`, `#F2F4F6`)를 유지하여 카드 컴포넌트가 입체적으로 부각되도록 처리.
